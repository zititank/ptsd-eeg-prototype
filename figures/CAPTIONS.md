# Captions

One line per image. Figures are regenerated by `make figures` (`tools/make_figures.py`), screenshots by
`make screenshots` (`tools/make_screenshots.py`). Every number comes from `results/*.csv` or `weights/`. No EEG or
EEG-derived value of the confidential cohort is plotted.

## Figures

| File | Caption |
|---|---|
| `figures/brain_vs_nonbrain.png` | SYNTHETIC illustration of the audit's label-free checks: a brain-like signal (correlated neighbouring channels, occipital alpha peak) passes the coupling QC; a non-brain signal (independent channels, flat spectrum, no alpha peak) fails it. In the real data, 46/46 control batch B rest files had no alpha peak. Generated by `tools/make_figures.py`; no cohort data. |
| `figures/roc_ci.png` | Out-of-fold ROC of the shipped model (C2G) with 95% bootstrap bands: AUC 0.816 vs all training controls, 0.982 vs control batch B, 0.435 [0.256, 0.604] vs valid controls (chance level). |
| `figures/v3_vs_c2g.png` | v3 vs the shipped model with 95% CIs: AUC 0.749 → 0.816, AUC vs valid controls 0.410 → 0.435, sensitivity 9/24 → 5/24, somatoform + 65+ FPR 21/97 → 13/97, flip rate 0.106 → 0.089, proxy points 30.59 → 36.30. |
| `figures/decision_rule.png` | Paired bootstrap Δ proxy points vs v3 (95% CI) for candidates C1–C4 and the pre-registered criteria: only C2 passed every check (C1 failed leakage gate G1; C3 and C4 failed criterion 1), so C2 shipped. |
| `figures/per_batch_auc_fpr.png` | Shipped model by batch: share scored ≥ 0.5 (Wilson 95% CI) and AUC vs each control batch; the separation comes from control batch B (AUC 0.982), not from valid controls (0.435). |
| `figures/coefficient_spread.png` | The 9000 standardized LDA coefficients of the shipped ensemble (90 LOSO members × 100 bags) per model input; clr_alpha_O is positive in 98.7% of fits, clr_beta_O is split around zero. |
| `figures/loso_diagram.png` | Nested leave-one-subject-out validation: each of the 90 subjects is held out once, an inner stratified 5-fold CV picks the LDA shrinkage, each member has 100 bags, and the deployed model is the mean of the 90 members. |
| `figures/pipeline_overview.png` | From a rest EDF to a score: minimum-data gate (fallback 24/90), cleaning and epoching, Welch PSD, the four Set A features, C1 transforms, the 90 × 100 bagged shrinkage-LDA ensemble, decision at 0.5. |
| `figures/task_duration_age_confound.png` | Adding the task-duration feature raises AUC vs valid controls (0.435 → 0.681 / 0.760) but flags 19/23 healthy controls aged 65+ (FPR 0.826 vs 0.000): an age confound, so these variants were not shipped. |
| `figures/external_scatter.png` | Public Mendeley PTSD data (n = 15 women, eyes-open rest): occipital relative alpha vs PCL-5 by device; device-stratified ρ = −0.04 [−0.63, 0.59], one-sided p = 0.45. Data: du Bois et al., Mendeley Data v3, doi:10.17632/gsxphk87mc.3 (CC BY 4.0); points unlabeled. |
| `figures/eeg_trace_public.png` | 10 s of eyes-open resting EEG from one public Mendeley recording (g.tec; Fp1/Fp2, T7/T8, PO3/PO4), resampled to 125 Hz and band-passed 2–40 Hz. Data: du Bois et al., Mendeley Data v3, doi:10.17632/gsxphk87mc.3 (CC BY 4.0). |
| `figures/eeg_trace_synthetic.png` | 10 s of the six channels (O1, T3, Fp1, Fp2, T4, O2) of one synthetic "high-alpha" subject from `examples/make_synthetic_edf.py`; not real EEG. |
